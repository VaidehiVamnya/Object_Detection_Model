## Dataset

The model was trained using a pothole detection dataset from Roboflow Universe.

Dataset link: [Pothole Detection Dataset](https://universe.roboflow.com/georgia-institute-of-technology-bwqcc/pothole-detection-mev9q/browse?queryText=&pageSize=50&startingIndex=0&browseQuery=true)

The full dataset is not included in this repository because of GitHub file size limits.
